# Rust Concurrency Issue Solved in Go

This Go program demonstrates a safe and simple way to handle producer-consumer concurrency using channels. It contrasts with potential complexities in languages like Rust where manual synchronization might be more error-prone, leading to crashes.

## Language

`go`

## How to Run

1. Save the code as `main.go`.
2. Run using `go run main.go`.
